## 各层职责

### 模型层 — Ollama

- 承担本地 LLM 推理
- 三个模型按场景切换：中文问答用 qwen2.5，英文/通用用 llama3.1，推理用 deepseek-r1
- 提供 OpenAI 兼容 API（`/v1/chat/completions`）
- 显存管理：同一时间只跑一个模型，`ollama stop` 释放显存

### 界面层 — Open WebUI

- 类 ChatGPT 交互界面，浏览器打开即用
- 连接 Ollama 后端
- 支持对话历史、多轮对话
- pip 一键安装，无需 Docker

### RAG 层 — AnythingLLM

- 让 AI 基于私有文档回答问题
- 内置向量数据库 LanceDB（零配置）
- 拖拽上传文档 → 自动切块 → 向量化 → 可检索
- 已上传：技术清单、学习笔记、简历关键信息

### 业务层 — Python 脚本

- 封装 OpenAI SDK 调用
- 多模型切换：改一行 `model` 参数即可
- 流式输出：逐字显示，体验更好
- 可扩展：Web API、自动化工作流等

### 展示层 — 个人网站

- `ai.html`：集中展示 AI 技能栈
- `notes.html`：学习笔记公开记录
- 证明"不仅会用，还能写出来"

## 为什么这样搭

1. **不依赖云服务**：Ollama 本地推理，断网也能用
2. **全免费**：模型开源、工具免费、硬件自己出
3. **面试可演示**：打开笔记本，本地跑起来，比 PPT 有说服力 100 倍
4. **渐进式**：从简单 `ollama run` 到 RAG 知识库到 Python 编程，技术深度层层递进
